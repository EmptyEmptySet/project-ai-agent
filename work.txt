【推免考核题目 —— 构建编程智能体（内容由“推免考核题目学生版.pdf”解析得出）】

一、任务目标
个人独立设计并实现一个编程智能体（coding agent）：它通过与大语言模型（LLM）交互，能够自主地
读写文件、执行命令，完成交给它的编程任务——类似一个简化的 Claude Code、Codex、OpenCode、
DeepSeek Harness 等。

二、功能与约束要求
1. 功能繁简不限，可以很简单，也可以做得完善。
2. 禁止事项：
   - 不允许在现成 agent 产品上封装界面；
   - 不得使用任何 agent 框架 / SDK（LangChain、LlamaIndex、OpenAI Agents SDK、Claude Agent SDK、
     AutoGen、CrewAI 等）。
3. 允许事项：
   - 可使用模型厂商的 API 客户端库；
   - 可使用 OpenAI 兼容网关；
   - 可使用模型原生的 tool calling 接口；
   - 不得依赖 API 服务端托管的代码执行或文件工具（如 Code Interpreter、Files API）。
4. 必须自行编写的重要逻辑（含但不限于）：
   - 对话历史与上下文管理；
   - 工具的定义与本地执行；
   - 模型输出的解析；
   - 循环终止条件；
   - 错误处理。

三、规则
1. 截止时间：2026 年 9 月 2 日 24:00（北京时间，即 9 月 3 日 0 点）。
2. 允许并鼓励使用任何 AI 工具辅助开发，但须对项目中的每一处设计负责。
3. agent 运行时调用的模型不限，编程语言不限。
4. API key 等凭据一律通过环境变量或未入库的配置文件提供，不得出现在仓库、README.txt 或视频中；
   若曾误提交，请立即作废更换。

四、提交物（共三项）
1. Git 仓库：须为题目发布后新建的公开仓库（GitHub、Gitee 均可）；保留完整提交历史；截止后不再推送。
   地址写在提交的 README.txt 中。
2. README.txt（1000 汉字以内）：Git 仓库地址；如何运行；特色功能说明；其它说明内容。
3. 视频（2 分钟以内）：演示 agent 完成一个真实编程任务的过程，并简要讲解功能实现；允许剪辑与加速
   播放；mp4 格式、不超过 200 MB。

五、提交方式
提交内容仅包含一个用姓名命名的 zip 文件（将 README.txt 和视频文件压缩成“姓名”.zip），
提交至：https://table.nju.edu.cn/dtable/forms/283d6c7d-475a-4f41-8baf-d3f45966ef2d/
（可重复提交，以最后一次为准）。

六、面试环节
现场播放视频后，简单介绍设计方案并回答评委提问；提问重点关注：是否理解 agent 为什么这样运转，
是否能为设计决策给出辩护。
